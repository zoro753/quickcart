# QuickCart

QuickCart is a React product listing page built with Vite. It showcases reusable
components, a product data module, and a responsive grid layout.

## Project Structure

- src/components: Header, ProductList, ProductCard
- src/data: product catalog
- src/styles: global and layout styles

## Getting Started

1. npm install
2. npm run dev

## Build

- npm run build
- npm run preview

## Notes

- Product data lives in src/data/products.js
- UI components are in src/components
